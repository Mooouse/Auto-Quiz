# AUTO QUIZ

Автомобильная HTML5-викторина на TypeScript + Vite. Одиночная игра, русский и английский интерфейс, локальный профиль. Используется предоставленный `game_platform.zip`: GameHost, жизненный цикл, аудио-шина и встроенный шрифт. Тяжёлого движка и 3D нет.

**Включён стартовый набор из 4 сгенерированных PNG:** Nissan Skyline GT-R R34, Toyota Supra A80, Mazda RX-7 FD и Nissan Silvia S15. Кнопка «Играть» запускает марафон; все четыре режима доступны в марафоне и на время. Без повторов сессия заканчивается после исчерпания набора. Для классики нужно минимум 10 машин. Это фотореалистичные изображения, созданные ИИ, а не документальные фотографии; детали могут отличаться от оригиналов. Происхождение и промпты: [docs/STARTER-ASSETS.md](docs/STARTER-ASSETS.md).

## Запуск

Нужен Node.js **22.18+** (проверено на 24.19).

```sh
npm ci
npm run setup
npm run dev
```

Открыть адрес Vite, обычно `http://127.0.0.1:5173`. Не открывать `index.html` через `file://`.

`setup` проверяет SHA-256 исходного архива, распаковывает его в `.platform` и устанавливает зависимости платформы. Архив остаётся неизменным; скачивать отдельный приватный репозиторий платформы не требуется. На Windows команды выполняются в терминале проекта.

## Что реализовано

- Фото / точный ввод / силуэт с вариантами / силуэт с точным вводом.
- Классика: 10 вопросов; марафон: до 3 ошибок; на время: 60 активных секунд.
- Очки 100 / 150 / 175 / 250, бонусы серии и скорости; XP, уровни, 7 званий.
- Без повторов автомобилей в одной сессии. Если база закончилась, марафон или игра на время завершается с явным сообщением. Бесконечная игра без повторов с конечной базой невозможна.
- Динамические категории и марки, правдоподобные уникальные варианты, предзагрузка следующего PNG.
- Коллекция с открытием за правильный ответ, поиск, фильтры, сортировка, сведения только из базы.
- 11 достижений с реальными условиями; профиль и статистика по каждому из 12 сочетаний режима и формата.
- Сохранение после каждого ответа, подтверждение сброса, никнейм, звук, уменьшение анимации, RU/EN.
- Импорт набора JSON + PNG прямо в браузере, хранение в IndexedDB.
- Пауза при скрытии вкладки; загрузка изображения не тратит игровое время. Автопереход в режиме на время включается в настройках.
- Онлайн обозначен «Скоро». Сервера, фиктивных игроков и рейтингов нет.

## Добавление автомобилей

Подробно: [docs/CARS.md](docs/CARS.md).

Для постоянной базы положите прозрачные PNG в `public/cars/` и записи в `public/data/cars.json`. Затем:

```sh
npm run validate:cars
npm run build
npm run preview
```

Для личного просмотра без пересборки: «Настройки → Каталог автомобилей → Добавить автомобили». Выберите **один JSON и все связанные PNG одновременно**. Импорт заменяет предыдущий локальный набор и остаётся только в этом браузере. Он не добавляет файлы в GitHub и не меняет сборку для других игроков.

Для классики нужно 10 машин в выбранном фильтре. Для вариантов ответа в других форматах нужно минимум 4; для точного ввода — минимум 1.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Браузерная проверка сама запускает локальный сервер для `dist` и закрывает его. Тестовые вымышленные автомобили и PNG создаются в памяти теста, **не входят в производственную базу**. Скриншоты появляются в игнорируемой папке `qa/`.

## Сборка и дальнейшая публикация

`npm run build` создаёт `dist/` с относительными путями, без обязательной регистрации и внешних изображений/шрифтов. Для размещения нужен обычный статический HTTP-сервер. Перед публичным релизом нужно добавить настоящую базу, проверить фотографии, пройти проверку реального устройства и превью CrazyGames.

**Текущая сборка — web/local. CrazyGames SDK ещё не подключён.** Граница интеграции — `services/platform.ts`; дальнейшая работа описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Готовность к приёму на портале не заявляется.

## Фотографии и права на изображения

В проекте есть страница «Фотографии и авторы». Для реальных снимков используется `origin: "photograph"` и обязательный набор `credits` (автор, источник, лицензия, её ссылка и выполненные изменения). Метаданные проверяются при импорте и сборке; четыре стартовые генерации отмечены `generated`.

Первые проверенные **страницы-источники**, ещё не обработанные и не включённые в игру: [docs/PHOTO-CANDIDATES.md](docs/PHOTO-CANDIDATES.md). Встроенный каталог по-прежнему содержит только четыре автомобиля, пока качественные прозрачные PNG не добавлены в `public/cars/`.

## Фото в рамках

Фото-режимы используют `photo` — оригинальную сцену с фоном в единой премиальной рамке. Режимы силуэта используют отдельный прозрачный `image` (PNG). Для старых импортированных каталогов без `photo` предусмотрена совместимость: вырезанный PNG остаётся рабочим во всех режимах.

Чтобы исключать кадры с другими автомобилями, GitHub Actions прогоняет подготовленные Wikimedia Commons снимки через консервативный детектор транспорта. Изображение с двумя найденными машинами или другой техникой, а также неоднозначный снимок не переводится в новый фотоформат. Результаты: `docs/PHOTO-FRAME-AUDIT.json`. Автоматическая проверка не заменяет ручной просмотр, особенно если вдалеке видны маленькие машины.
