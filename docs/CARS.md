# База автомобилей

В `public/data/cars.json` включены четыре машины со сгенерированными прозрачными PNG. Их можно дополнить своими фотографиями. Происхождение: [STARTER-ASSETS.md](STARTER-ASSETS.md).

Формат базы — массив. Пример записи:

```json
[
  {
    "id": "nissan-skyline-r34-gtr",
    "brand": "Nissan",
    "model": "Skyline GT-R",
    "generation": "R34",
    "modification": "",
    "fullName": "Nissan Skyline GT-R R34",
    "aliases": ["Nissan Skyline R34 GT-R", "Nissan Skyline GTR R34"],
    "image": "cars/nissan-skyline-r34.png",
    "categories": ["JDM", "Japanese", "Sports Cars"],
    "difficulty": 2
  }
]
```

1. Подтвердите точную модель, поколение и модификацию по вашим исходным данным. Имя файла не используется для определения автомобиля.
2. Сохраните PNG с прозрачным фоном в `public/cars/`. Вся машина должна помещаться в изображении, без обрезанных колёс, зеркал и спойлеров. Изображение выводится через `object-fit: contain`.
3. Добавьте запись. `id` — постоянный уникальный идентификатор из строчных латинских букв, цифр и дефисов. Он связывает машину с накопленной статистикой; не меняйте его при обновлении фотографии.
4. Запустите `npm run validate:cars` и пересоберите игру.

Обязательны `id`, `brand`, `model`, `fullName`, `aliases` (может быть пустым массивом), `image`, непустой массив `categories`, целое `difficulty` от 1 до 5. `generation`, `modification`, `years`, `info` — строки; отсутствующие сведения не отображаются. Не придумывайте годы и характеристики. Сложность хранится в базе и помогает подбирать похожие варианты; количество очков определяется игровым режимом.

Путь относительно `public`: `cars/name.png` или `assets/cars/name.png`. Ведущий `/` допускается в исходных данных и нормализуется для размещения игры во вложенной папке. Внешние URL и `..` запрещены. При импорте в браузере имена PNG должны однозначно совпадать с записью. Для обычного выбора нескольких файлов удобнее использовать уникальные имена без вложенных папок.

## Строгие ответы

Сравнение выполняется только с `fullName` и явно заданными `aliases`. Регистр, пробелы, дефисы и пунктуация игнорируются. Порядок слов автоматически **не** переставляется: впишите допустимые варианты в `aliases`.

Например, для `BMW M5 CS F90` добавьте `BMW M5 F90 CS`. Не добавляйте просто `BMW M5`, если вопрос требует CS и F90. Опечатки не исправляются автоматически, приблизительное совпадение не используется.

Проверка запрещает повторяющиеся ID, одинаковые нормализованные имена/алиасы у разных записей, одинаковую комбинацию марки/модели/поколения/модификации и один PNG для разных машин. Это предотвращает неоднозначные варианты ответа. Семантические синонимы в разных полях невозможно гарантированно распознать программно: для одной машины используйте одну запись и алиасы.

## Категории

Фильтры автоматически строятся по фактическим записям. Предустановленные переводы есть для:

| Ключ | Русское название |
|---|---|
| JDM | JDM / Японские |
| Japanese | Японские |
| German | Немецкие |
| American | Американские |
| European | Европейские |
| Supercars | Суперкары |
| Hypercars | Гиперкары |
| Sports Cars | Спорткары |
| Classic | Классические автомобили |
| SUV | Внедорожники |
| Sedan | Седаны |

Произвольные дополнительные категории разрешены и показываются как записаны. Несколько категорий у одной машины допустимы. Для японского и немецкого достижений используйте `Japanese`/`JDM` и `German` соответственно.

## Проверка изображений

Команда сборки проверяет наличие файлов и сигнатуру PNG. При импорте и перед игровым вопросом браузер дополнительно декодирует изображение и проверяет наличие прозрачных и видимых пикселей. Непрозрачный фон не подходит для точного силуэта: будет показана ошибка, таймер останется на паузе.

Силуэт получается через `filter: brightness(0)`, анимация раскрытия возвращает цвет. Альфа-канал и исходные пропорции сохраняются. Желательно заранее оптимизировать PNG, не ухудшая детали: размер готовой игры в основном будет зависеть от фотографий.

## Локальные данные

Профиль: `localStorage`, ключ `autoquiz.profile.v1`. Импорт: IndexedDB `autoquiz.catalog.v1`. Данные привязаны к браузеру и origin. При переносе на другой адрес, очистке данных сайта или приватном режиме постоянное сохранение не гарантируется. Ошибка записи показывается в интерфейсе. Сброс прогресса требует подтверждения и не удаляет импортированные изображения.

## Реальные фотографии и авторы

Для реальных фотографий указывайте `origin: "photograph"` и все поля `credits`. Источники, авторы, лицензии и обработка отображаются на странице «Фотографии и авторы», доступной через раздел импорта и ссылку в подвале сайта.

```json
{
  "origin": "photograph",
  "credits": {
    "author": "Имя фотографа на странице оригинала",
    "sourceUrl": "https://commons.wikimedia.org/wiki/File:Original.jpg",
    "license": "CC BY-SA 4.0",
    "licenseUrl": "https://creativecommons.org/licenses/by-sa/4.0/",
    "changes": "Background removed; exported as transparent PNG"
  }
}
```

Для сгенерированных изображений — `origin: "generated"`. Старые импорты без поля остаются совместимыми, но происхождение показывается как неуказанное. Адреса источника и лицензии принимаются только по HTTPS.

Проверяйте автора и лицензию **для каждого файла**; для CC BY-SA соблюдайте условия Attribution и ShareAlike для переработки. Удаление фона тоже является изменением фотографии. Не добавляйте снимки с неясными правами или недостоверной точной комплектацией. Проверяйте колёса, зеркала, спойлер и отсутствие соседних автомобилей. Первые ссылки на источники: [PHOTO-CANDIDATES.md](PHOTO-CANDIDATES.md).

## Новый формат: фото в рамке + отдельный силуэт

Для полноцветных режимов `photo` (по желанию) задаёт локальный JPEG/PNG/WebP с исходным фоном. В `image` **по-прежнему** должен находиться прозрачный PNG только с автомобилем: он используется в режимах силуэта. В старых наборах, где `photo` отсутствует, игра продолжает использовать имеющийся прозрачный PNG в обоих режимах. Пакетный импорт теперь принимает JSON + оба файла каждой машины.

Пример части одной записи:

```json
{
  "image": "cars/bmw-m3-e46.png",
  "photo": "cars/bmw-m3-e46-photo.jpg",
  "origin": "photograph"
}
```

**Фильтр сцен:** в исходном кадре должен быть один автомобиль. Другие легковые машины, автобусы, мотоциклы или грузовики на заднем плане недопустимы; нечёткие, перекрытые и обрезанные авто тоже отвергаются. Для существующего набора Wikimedia Commons скрипт `scripts/approve-photos.py` проверяет снимки офлайн-моделью детекции транспорта, и публикует `photo` лишь если обнаружен ровно один автомобиль без других транспортных средств. Подозрительные фотографии **не попадают в игру с фоном**: остаются старые вырезанные PNG. Решения документируются в `docs/PHOTO-FRAME-AUDIT.json`. Модель не гарантирует обнаружение маленьких дальних машин, поэтому финальная визуальная проверка фотографий обязательна. Не удаляйте `image` после добавления `photo`.

Оригинальный фон остаётся нетронутым: фотография уменьшается и сохраняется в JPEG, но не вырезается по контуру. Для силуэта применяется отдельный прозрачный PNG из уже подготовленного набора. Предпочтительны кадры без отвлекающих объектов и с читаемым кузовом. Новый JPEG сохраняется как переработка с указанием источника, автора, лицензии и действий над файлом.

В `docs/PHOTO-FRAME-AUDIT.json` `approved` означает **автоматически прошёл скрининг**, а не визуально одобрен человеком. Перед публикацией на CrazyGames нужен ручной контроль на фоне белой и чёрной тем.
